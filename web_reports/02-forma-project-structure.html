Project structure in Forma

On 13 October 2026 the Snowdon Towers trial showed a Data Management project with ten modules in the left navigation and five type folders under Project Files. This page records that structure. One folder was opened.

The five folders group files by type. They sit directly under Project Files. They are a practice filing structure. They are separate from the ISO 19650 states Work in Progress, Shared, Published, and Archived, and the screen showed no parent folder named Digital Engineering Practice.

The project shell

The header read Autodesk Forma, with Data Management selected, and the project name Construction: Sample Project – Snowdon Towers. A trial banner read “Welcome to your 30 day trial – Forma Data Management.” The account mark in the corner was NL.

Files opened on a welcome panel: “Welcome to Files. Keep your project data centralized, accessible, and secure with permission controls.” That sentence is the product’s own introduction. This session did not open a permissions screen, so member groups and folder access stay unrecorded.

The left navigation is the project’s module list. Files was the working area. Reviews was opened only as far as approval-workflow settings, which were empty. The other modules were visible and left closed.

Reviews beside the folders

Approval workflow lives under Reviews, in Settings, rather than inside a folder. Two tabs were present: Approval workflow and Draft approval workflow. The page read “No workflows,” and the create dialog offered templates from one step through five steps. None was created. Submit for review on S102 therefore had an empty workflow list. The file can sit in 01_Design Files at V1 while the project still has no review path.
