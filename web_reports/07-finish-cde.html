2. Work sequence

  1. Confirm each file in Forma. Open the five folders. Check that the 14 names in Report 03 are present. Preview PDFs where the viewer allows it. Note anything the trial account hides or refuses.
  2. Write the document register from the screen, one row per file. Use the columns below. Copy only values Forma or the file shows. Leave revision, suitability, and review status blank when they are absent.
  3. Inspect one file for versions and review. Use S102-Main Level.pdf. Open file details and version history. If the account allows a comment, label it as a practice comment. A practice comment is a learning record. It is not an engineering approval and it does not change the workflow step to −4.
  4. Record which controls exist. For permissions, attributes, versions, reviews, issues, and export, write one of: available and used, available and not used, or absent in this trial.
  5. Stop at the register. When the register and the capability notes are saved, step −7 can be closed. Export, cleaning, and reporting are Report 08.
